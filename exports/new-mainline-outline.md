# 零基础 Python 主线大纲（16 关）

> 目标用户：第一次写代码的大一新生。
> 目标不是"猜对 Python 表达式"，而是"能独立写出 20-40 行、能跑、能改的小程序"。
> 旧题库 6090 题不删除，降级为进阶练习池，不再承担主线教学。

---

## 0. 这份大纲解决什么

旧题库的根本问题不是难度高，而是**考错了能力**：

- 6090 题里 0 道要求写代码，全部四选一；
- 80.9% 是"下列代码输出是？"，考的是人肉执行解释器；
- 第 1 关就出现负数取模、运算符优先级、`int('16.8')` 的异常类型；
- 99% 的题由 208 个模板换数字生成，容易变成背本关答案。

新主线只保留一条判断标准：**学完这一关，学习者能做出一个可运行的小东西。**

---

## 1. 设计原则

1. **一关一个任务**：每关都有一个可见产出，不是"学完一个语法点"。
2. **题型以读、补、找、写为主**：读意图 → 补全 → 找 Bug → 独立写。
3. **一关 8 题，6 题正确即通过（75%）**：允许犯错，错题换同知识点变式重做，不整关推翻。
4. **不考语言边角**：负数取模、运算符优先级、`for...else`、装饰器、生成器、pandas、正则、LeetCode 全部后移。
5. **旧题不浪费**：按标签映射成每关的"练习池"，主线之外自愿刷。

## 3. 每关详情

每关默认 8 题：读意图 2、补全 2、找 Bug 2、选实现 1、概念 1，全部四选一。通过线 6/8。

### L1 第一行代码

- **能力目标**：能让程序输出一行文字；知道字符串要加引号。
- **任务产出**：打印一张三行的自我介绍卡。
- **核心知识**：`print()`、单双引号、`\n` 换行、注释。
- **示例题**：
  - 找 Bug：下面哪一行能正确输出"你好"？A. `print(你好)` B. `print("你好")` C. `print('你好')` D. B 和 C 都对。答案 D。
  - 补全：`print("你好，____")`，要求输出"你好，小明"。
- **不考**：三引号本质是字符串表达式、PEP 8 缩进细节、`end` 参数配合换行的视觉题。

### L2 变量与输入

- **能力目标**：能把用户输入存进变量，并转成数字参与计算。
- **任务产出**：输入姓名和年龄，输出"小明明年 19 岁"。
- **核心知识**：变量赋值、`input()` 永远返回字符串、`int()/float()`、f-string 基础。
- **示例题**：
  - 读意图：`age = int(input("年龄："))` 中 `int` 的作用是什么？
  - 找 Bug：`age = input("年龄："); print(age + 1)` 为什么报 TypeError？
  - 写代码：读入姓名和年龄，输出明年年龄。
- **不考**：`int('16.8')` 的 ValueError/TypeError 区分、编码问题。

### L3 数字与计算

- **能力目标**：能选对运算符解决生活里的计算。
- **任务产出**：算三科平均分、算找零、算分糖果剩余。
- **核心知识**：`+ - * /`、`//` 整除、`%` 取余、f-string 保留小数。
- **示例题**：
  - 场景：31 颗糖平均分给 8 人，剩几颗？选 `31 % 8`。
  - 补全：`avg = total ____ len(scores)`。
  - 写代码：读入三科成绩，输出平均分（保留 1 位小数）。
- **不考**：负数取模、负数整除、多运算符优先级心算。

### L4 布尔与 if

- **能力目标**：能让程序根据条件执行不同代码。
- **任务产出**：输入年龄判断是否成年；输入分数判断是否及格。
- **核心知识**：比较运算符、`and/or/not`、`if` 缩进、`=` 与 `==`。
- **示例题**：
  - 补全：`if score ____ 60: print("及格")`。
  - 找 Bug：`if score = 60:` 错在哪？
  - 写代码：输入年龄，输出"成年"或"未成年"。
- **不考**：`bool(None)`、空列表/空字典的真值表。

### L5 多分支

- **能力目标**：会写 `if/elif/else`，理解分支顺序和边界。
- **任务产出**：成绩等级 A/B/C/D。
- **核心知识**：`elif`、区间判断、边界值、分支顺序。
- **示例题**：
  - 找 Bug：先判断 `>=60` 再判断 `>=90`，90 分会被判成什么？
  - 写代码：90 以上 A、80-89 B、60-79 C、60 以下 D。
- **不考**：三层以上嵌套、复杂布尔组合。

### L6 for 循环

- **能力目标**：会让一段代码重复固定次数。
- **任务产出**：打印 1-10、打印乘法表的一行、求 1-100 的和。
- **核心知识**：`for`、`range(start, stop, step)`、循环变量、循环体缩进。
- **示例题**：
  - 补全：`for i in range(____): print(i)` 输出 1-5。
  - 读意图：`range(5)` 循环几次？输出哪些数？
  - 写代码：打印 1-10 里的偶数。
- **不考**：负步长、`for...else`、复杂嵌套循环计算。

### L7 while 循环

- **能力目标**：会在条件满足时一直重复，知道如何避免死循环。
- **任务产出**：猜数字，直到猜中为止。
- **核心知识**：`while`、循环变量更新、`break`、输入循环。
- **示例题**：
  - 找 Bug：`while guess != target: print("再猜")` 缺了什么导致死循环？
  - 补全：`while guess ____ target:`。
  - 写代码：固定答案 7，让用户反复输入直到猜中。
- **不考**：`while...else`、复杂状态机。

### L8 累加与统计

- **能力目标**：会在循环里累加、计数、找最值。
- **任务产出**：给一组成绩，求总分、平均分、最高分。
- **核心知识**：累加器初始化、计数器、`max/min`、条件筛选。
- **示例题**：
  - 找 Bug：`total = 0` 写在循环里，为什么每次都被清零？
  - 补全：`total = total + ____`。
  - 写代码：求列表总分和平均分。
- **不考**：生成器表达式、`sum(x for x in ...)` 的写法。

### L9 列表基础

- **能力目标**：能存一组数据并访问、添加、删除。
- **任务产出**：待办清单的添加、查看、删除。
- **核心知识**：索引从 0 开始、`append`、`remove/pop`、`len`、遍历。
- **示例题**：
  - 补全：`todos.____("买牛奶")`。
  - 找 Bug：`todos` 只有 3 项，访问 `todos[3]` 会怎样？
  - 写代码：创建列表，添加两项，逐行打印。
- **不考**：切片步长、浅拷贝、列表推导式。

### L10 列表统计

- **能力目标**：会筛选、计数、排序。
- **任务产出**：统计及格人数、平均分、最高分姓名。
- **核心知识**：`for item in list`、条件计数、`sort/sorted`。
- **示例题**：
  - 补全：`if score >= 60: pass_count ____ 1`。
  - 找 Bug：一边遍历列表一边 `remove` 为什么会漏项？
  - 写代码：统计成绩列表里的及格人数。
- **不考**：列表推导式的复杂嵌套。

### L11 字典

- **能力目标**：会用键值存一条结构化数据。
- **任务产出**：通讯录（姓名 → 电话）、词频统计。
- **核心知识**：字典创建、`d[key]`、`get()`、`keys/values/items`、遍历。
- **示例题**：
  - 补全：`count[w] = count.get(w, 0) + ____`。
  - 找 Bug：`count[w] += 1` 在 `w` 不存在时为什么会 KeyError？
  - 写代码：统计一句话里每个单词出现的次数。
- **不考**：哈希原理、集合、字典推导式。

### L12 列表 + 字典

- **能力目标**：会用"列表套字典"表示一张表。
- **任务产出**：学生成绩表，按条件筛选姓名。
- **核心知识**：数据结构设计、嵌套遍历、字段访问。
- **示例题**：
  - 读意图：`students[0]["name"]` 取到的是什么？
  - 补全：遍历学生列表，把所有及格学生的姓名加入结果列表。
  - 写代码：找出最高分学生的姓名。
- **不考**：pandas、数据库。

### L13 函数入门

- **能力目标**：会把重复逻辑封装成函数。
- **任务产出**：写 `average(nums)` 和 `is_pass(score)`。
- **核心知识**：`def`、参数、调用、函数体缩进、`return` 基础。
- **示例题**：
  - 补全：`def average(nums): return ____`。
  - 找 Bug：定义了函数但从来没有调用，为什么没输出？
  - 写代码：写一个 `is_pass(score)`，及格返回 True。
- **不考**：默认参数陷阱、`*args/**kwargs`、装饰器。

### L14 返回值与作用域

- **能力目标**：理解 `return` 和 `print` 的区别，理解局部变量。
- **任务产出**：组合多个小函数完成成绩统计。
- **核心知识**：`return`、`None`、局部/全局变量、函数调用链。
- **示例题**：
  - 读意图：函数里 `print` 了但没 `return`，调用处拿到什么？
  - 找 Bug：函数返回了值，但主程序没有接收。
  - 写代码：用 `average()` 和 `is_pass()` 组合输出班级是否及格。
- **不考**：闭包、`nonlocal`、递归。

### L15 文件与异常

- **能力目标**：会把数据存到文件、读回来，并处理坏输入。
- **任务产出**：待办清单保存到文件，重启后还能读出来。
- **核心知识**：`open`、`with`、读/写模式、`strip/split`、`try/except ValueError`。
- **示例题**：
  - 补全：`with open("todos.txt", "____") as f:` 写入用哪个模式？
  - 找 Bug：读出来的每行末尾有换行，为什么比较失败？
  - 写代码：把列表写入文件，再读回来打印。
- **不考**：编码细节、自定义异常、文件指针。

### L16 综合演练：命令行待办 / 记账本

- **能力目标**：把变量、列表/字典、函数、文件、异常串成一个完整程序的全貌。
- **形式**：不设写代码题。用"选实现 + 补全 + 找 Bug"围绕同一个项目反复出题：数据结构怎么设计、菜单循环怎么写、存盘读盘补哪行、报错改哪里。
- **项目拆解（8 题）**：
  1. 设计数据结构（列表 + 字典）。
  2. 写 `add_item()`。
  3. 写 `list_items()`。
  4. 写 `remove_item()`。
  5. 写 `save()` / `load()`。
  6. 用 `while` 做菜单循环。
  7. 用 `try/except` 处理非法输入。
  8. 跑通 3 个验收用例。
- **验收用例**：
  - 添加两条待办，查看能看到两条。
  - 删除一条，查看只剩一条。
  - 退出重进，数据还在。
- **不考**：网络请求、爬虫、pandas、算法题。

## 4. 题型定义与判题

| 题型 | 占比 | 长什么样 | 判题方式 |
|---|---|---|---|
| 读意图 | 25% | "这段代码想做什么？"不要求精确输出 | 选择题 |
| 补全 | 25% | 挖 1-2 个空，填代码 | 选择/填空 |
| 找 Bug | 25% | 给代码 + 报错/错误现象，选错行或改法 | 选择/定位 |
| 选实现 | 12.5% | 给一个任务和 4 段代码，只有 1 段能正确完成 | 选择题 |
| 概念 | 12.5% | 场景里的概念辨析 | 选择题 |

**说明**：本站不设"动手写代码"题（原方案需要截图上传 + 自评，已取消）。"写代码"的训练目标由"选实现 + 补全 + 找 Bug"三种选择题共同承担：学习者始终在做代码判断，但不需要离开页面去编辑器。

## 5. 关卡机制

- 每关 8 题，6 题正确通过（75%）。
- 错题不整关重来，只把错题对应的知识点换一道变式重做。
- 每关结束显示"本关产出"：一段可运行的代码或一个截图式结果。
- 进度按关卡保存，不再按题量硬切。
- 旧存档 `mnk_state` 与新主线不兼容，原型阶段直接重置；正式版再做迁移。

## 6. 旧题库怎么处理

| 旧题类型 | 处理 |
|---|---|
| 基础语法、字符串、列表、字典、函数、文件 | 按 `tag` 映射到新关卡，作为"练习池"，每关学完解锁 10-20 题 |
| 负数取模/整除、运算符优先级、`for...else`、装饰器、生成器 | 移到"进阶池"，主线不出现 |
| pandas、正则、爬虫、LeetCode | 移到"项目/进阶池"，不当主线 |
| Q0027 这类不可见字符畸形题 | 直接修或删 |
| 纯换数字、同一模板超过 5 遍的题 | 主线不用；练习池里每个模板最多留 3 道 |

旧题库仍有价值，但定位从"主线关卡"改成"主线学完后的巩固练习"。

## 8. 验收标准

- 一个没写过代码的人，能在不看答案的情况下完成 L1-L3，并说清每行在做什么。
- 每关都有可展示的产出，而不是只看到一个分数。
- L16 结束后，学习者能独立写出一个 20-40 行、能保存数据的小程序。
- 主线题目里，"猜精确输出"不超过 10%，"写/补/找 Bug"合计不低于 65%。
